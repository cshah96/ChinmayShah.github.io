I am developing a seamless biomechanics data processing pipeline that makes it easier to collect Vicon motion capture data and synchronize it with other systems. The pipeline automates Vicon data processing and cleaning, and connects via a GUI to OpenSim through a Python interface, enabling seamless computation of biomechanical data metrics such as inverse kinematics and inverse dynamics.
