To separate the sensing layer from the exoskeleton and enable standalone wearable sensor data collection, we developed a copy of the Georgia Tech Second Skin sensor suit, which uses wired IMUs and foot insoles to collect data. We are now developing a set of custom PCB boards to build new wireless IMUs, simplifying the system for real-time control. We are also building a suite of IK tools connected to MuJoCo for data collection.
